# Haiku 5.5 pilot and visual evidence

Run date: 2026-10-16. Model: `claude-haiku-5-5`, thinking disabled. Development seeds 0 and 1 only; the frozen final layouts (10–49) were not used. Prompt and screenshots are generated by [pilot.py](pilot.py). Raw responses, actions, ledgers, feedback and usage are in [results/pilot.jsonl](results/pilot.jsonl); aggregate counts are in [results/pilot.summary.json](results/pilot.summary.json).

Eight screenshot-based model decisions were replayed on clean and defective pages, giving 16 browser episodes. The clean action achieved the required result in 8/8 episodes (2/2 per task). The same action failed the required round trip in 8/8 defect episodes. These tiny counts establish that the controls and image resolution are usable for this pilot; they are not an estimate of model reliability on final layouts.

Measured API usage: **7,192 input tokens, 146 output tokens, $0.000792** total. The plan's earlier $0.05 pilot estimate was deliberately conservative. The full experiment's cost must still be tracked from actual billed tokens; a single eight-call pilot is not enough to guarantee the full-run estimate.

The most useful trace is scaled click seed 1. The page instructed the model to click Item 15. Haiku returned `{"action":"click","x":150,"y":413}` in the 900 × 600 image. The correct conversion clicked `(200, 550.67)` CSS pixels and the page ledger recorded `button-15`. The faulty executor used `(150, 413)` CSS pixels; the ledger recorded `button-10`. The page visibly selected Item 10. This is a real model decision replayed through an injected harness fault.

The GIF uses actual before and after screenshots and added markers; it is an annotated screenshot sequence, not continuous video. The fault was deliberately injected on a local page. It does not establish how often coordinate errors occur on real sites.

Other traces: the search decision submitted an exact record name cleanly but gained `[im_end]` in the faulty parser; the iframe click selected the correct row while the faulty feedback said “No detectable change”; the chart hover worked while the early observation missed the tooltip. The eight clean successes do not justify a statistical claim that Haiku's success rate exceeds the plan's 70% stop threshold. They only satisfy the pilot's basic go/no-go check; the 20-layout clean run in Phase B must measure that rate.
